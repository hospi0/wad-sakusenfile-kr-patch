# 월드 어드밴스드 대전략 작전 파일 (세가 새턴 일본판) 한글 패치

> **내려받기:** [릴리즈 페이지](https://github.com/hospi0/wad-sakusenfile-kr-patch/releases/latest) — v0.9
>
> 이 저장소에는 도구와 작업 문서만 있습니다(ROM·빌드 결과물 없음).

같은 프로젝트의 다른 게임: [강철의 전풍](https://github.com/hospi0/wad-koutetsu-kr-patch) (패치는 게임별로 따로 적용합니다)

## 내용

- 시나리오 41개 브리핑·승리 조건 문장, 캠페인 이야기
- 메뉴·메시지·턴 시작·이벤트·저장 화면·설정 화면 글자, 턴 화면 나라·부대 이름
- 무기·지형 이름(작은 글자는 한글), 유닛·나라·거점 이름(작은 글자는 영문)
- 큰 유닛 이름, 시나리오 제목·설명, 지구본 연표, 엔딩 글
- 그림 글자: 타이틀 띠, 작전 버튼, 병기 타입 메뉴, 상황 표, 유닛 정보, 설정 버튼, 지도 지명 15장, 자료 제공 화면

## 알려진 점

- 시험판입니다. 전체 플레이 검증을 마치지 않았습니다.
- 표시 칸이 좁아 작은 글자의 고유 이름은 영문으로, 시나리오 설명 일부는 줄여서 넣었습니다.
- 대전략 로고(큰 한자)와 동영상은 원본 그대로입니다.
- 패치 전 세이브와 세이브스테이트는 쓰지 마세요.

## 빌드 순서

```
python tools/build_f.py --write
python tools/make_dist.py
```

작업 기록은 `docs/00_초기조사.md`. 두 게임이 도구를 함께 씁니다.
